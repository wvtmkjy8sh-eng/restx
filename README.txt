RestX — PWA de descanso para academia

Inclui:
• diminuir/aumentar em 5 segundos
• reset
• iniciar
• presets 30/45/60/90/120 s
• alerta WAV intenso e longo
• vibração quando suportada
• preparação automática do próximo descanso
• PWA para celular, tablet e desktop
• layout responsivo
• áudio local para iOS/Android

iPhone/iPad:
1. Abra pelo Safari em HTTPS.
2. Toque em Iniciar uma vez: isso autoriza o áudio.
3. Para instalar: Compartilhar > Adicionar à Tela de Início.
4. Teste com volume de mídia alto. O comportamento de áudio pode variar conforme modo silencioso/versão do iOS.
5. Para máxima confiabilidade, mantenha o RestX aberto em primeiro plano; iOS pode suspender JavaScript/áudio em segundo plano ou com tela bloqueada.

Android:
Chrome/Edge > menu > Instalar app/Adicionar à tela inicial.

PWA/service worker exigem HTTPS ou localhost; não use file://.
